# SPCL Internship Tasks

A collection of projects completed during SPCL internship periods.

## Projects

### 1. Luxury Car Dealer Web
A premium luxury vehicle showcase and sales platform built with modern web technologies.
- **Location**: `luxury_car_dealer_web/`
- **Tech Stack**: React, TypeScript, Tailwind CSS, shadcn/ui, Framer Motion
- **Features**: Vehicle inventory, financing calculator, testimonials, responsive design
- **Deployed**: [Luxury Drive Online](https://luxury-drive-online.vercel.app)

### 2. Portfolio Website
Personal portfolio showcasing innovative web solutions and premium designs tailored for impactful digital experiences.
- **Location**: `portfolio-website/`
- **Tech Stack**: HTML, CSS, JavaScript
- **Deployed**: [Portfolio Website](https://portfolio-website-7ibx.vercel.app/)

### 3. Connect Sphere Summit
An event management system for planning and organizing events with full backend and frontend.
- **Location**: `connect_sphere_summit/`
- **Tech Stack**: React, TypeScript, Node.js, SQLite
- **Features**: Event creation, attendee management, speaker profiles, networking, booking system

## Getting Started

Each project has its own installation and setup instructions. Navigate to the respective project directory for more details.

```bash
# For Luxury Car Dealer Web
cd luxury_car_dealer_web
npm install
npm run dev

# For Portfolio Website
cd portfolio-website
# Check the project's README for setup

# For Connect Sphere Summit
cd connect_sphere_summit
npm install
npm start
```
